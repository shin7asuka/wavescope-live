# WaveScope Live

黄金、白银与WTI连续期货的秒级动态浪型分析仪表盘。

## 数据与更新

- 实时口径：TradingView 数据流中的 `OANDA:XAUUSD`、`OANDA:XAGUSD`、`TVC:USOIL`
- 前端每秒请求一次，后端设有0.85秒缓存以控制重复请求
- 1分钟、5分钟、15分钟和1小时周期
- 日K与周K用于观察大级别结构
- 上游报价没有新成交时，分析时间继续更新，但数据时间保持不变
- 可为黄金、白银和WTI分别添加“上穿”或“下破”目标价提醒；服务器每5秒读取相关品种的最新1分钟报价
- 分钟与小时图在横向时间轴上标注澳大利亚、日本、中国、印度、德国、英国和美国主要现货交易所的开收盘节点
- 参考核心时段：ASX 10:00–16:00、JPX 09:00–15:30、SSE 09:30–15:00、NSE 09:15–15:30、Xetra 09:00–17:30、LSE 08:00–16:30、NYSE 09:30–16:00，均为当地时间
- 所有节点通过 IANA 时区换算，自动处理澳大利亚、欧洲和美国夏令时；交易所节假日与临时调整不在前端日历中
- 横轴可在北京时间（Asia/Shanghai）和美国纽约时间（America/New_York，自动切换 EST/EDT）之间切换；十字光标、数据时间及分析时钟同步切换
- 时段核验：[ASX](https://www.asx.com.au/markets/market-resources/trading-hours-calendar/cash-market-trading-hours)、[JPX](https://www.jpx.co.jp/english/systems/equities-trading/index.html)、[SSE](https://english.sse.com.cn/start/trading/schedule/)、[NSE](https://www.nseindia.com/static/market-data/market-timings)、[Xetra](https://www.cashmarket.deutsche-boerse.com/cash-en/trading/trading-calendar-and-trading-hours)、[LSE](https://www.londonstockexchange.com/trade/trading-hours)、[NYSE](https://www.nyse.com/trade/hours-calendars)

## 浪型算法

- 使用仅在反转达到ATR阈值后确认的在线ZigZag，避免直接使用未来数据
- 5浪推动、W-X-Y复杂调整、ABC锯齿调整使用不同摆动灵敏度形成候选路径
- 5浪执行艾略特推动浪硬规则：浪2不越起点、浪3越过浪1终点、浪3不得最短、浪4不得进入浪1区域
- ABC按锯齿调整校验；7段按 A-B-C-X-A'-B'-C'（W-X-Y双重锯齿）校验
- 未通过规则的结构会明确降级为候选并显示通过项数，不再直接当作有效浪型
- 当前结构选择加入末端时间衰减，不再优先沿用较早的完整5浪；只有末端位于最近2根K线内才显示“第5浪刚完成”
- 较早完成的5浪改为“完成后续段观察”，实时末端仅显示“第5浪延伸候选”，避免长期固定显示第五浪完成
- 5浪尚未结束时，单独计算第1至第5浪的阶段条件概率；5浪结束后改为评估第6笔/A浪、第7笔/B浪及下一浪型（C浪或新推动）的条件概率
- “第6笔、第7笔”仅表示5浪之后的摆动笔数，不作为艾略特推动浪中的第6浪、第7浪
- 若最新价重新越过原第5浪端点（含0.15 ATR容差），撤销“5浪已完成”分支并按第5浪延伸/推动结构重新编号
- 所有第1至第7阶段候选均显示该段是上升推动、下降调整、上升反弹或下降延续
- 已确认浪型从最后一个确认拐点实时延伸至最新价格，并用“实时”箭头标记未确认末端
- 每个阶段明确标注上升或下降方向，图中波段编号带方向箭头
- 根据各浪型摆动高低点、区间边界、斐波那契回撤和扩展动态聚合支撑阻力
- 图中显示S1-S3与R1-R3，每个价位附带启发式强度概率和结构来源
- 不再使用或显示人工指定的宏观支撑位、阻力位和多空轴；图中S1-S3、R1-R3全部来自当前K线结构、斐波那契聚类与摆动点的动态计算
- 大级别下降通道的上下轨、中轴、带内位置与覆盖率每秒重算
- XAUUSD主趋势通道按用户截图采用动态日K锚定法：从2026年3月30日起显示，起点后22天内的主高点作为首个上轨锚点，之后最近一个已确认日线摆动高点作为第二锚点
- 上轨采用日线高点残差99%分位、下轨采用低点残差6%分位并增加6%日ATR缓冲，以匹配截图约800美元宽度；允许少数历史极端影线穿轨，避免单根异常K线过度扭曲主通道
- 通道中轴以最近90个日线交易时段的平均收盘价作为滚动均衡中心，并将单次平移限制在通道宽度的8%以内；当前实时收盘替换最后一个日线值，因此市场变化会逐秒进入中轴计算，但不会让长期通道随每个跳价剧烈抖动
- 最近实时K线的高低价每秒检查，若突破稳健外轨则立即扩轨；新日线高点确认后才改变斜率，减少盘中抖动
- 黄金长期锚定通道绘制在日K与周K；1分、5分、15分和1小时图改用各周期的局部线性回归包络，避免约800美元的日线通道压缩分钟K线
- 右侧“黄金动态趋势带”在所有周期继续显示同一条长期锚定通道的上下轨、中轴、位置与覆盖率；日线宏观数据缓存5秒，实时K线仍每秒参与长期通道边界更新
- XAGUSD与WTI继续按分周期窗口建立线性回归包络：分钟180根、小时120根、日线90根、周线26根
- 新增日K和周K；大级别约800美元下降结构应优先在日K或周K观察
- 图表标签默认隐藏以减少遮挡；点击图例区“显示标签/隐藏标签”可切换浪号、价格轴和通道标签，线条始终保留
- 切换品种或周期时自动定位到最新K线并重置价格轴；不同周期使用不同可见K线数量，每秒刷新不会打断用户手动缩放
- 概率由趋势强度、摆动密度、重叠度、方向效率和结构完整性经Softmax归一化产生
- 当前概率是启发式结构评分，不是经过历史样本校准的真实概率

## 价位提醒

- 点击右下角“价位提醒”，先启用系统通知，再选择品种、上穿/下破和目标价
- 规则保存在服务器SQLite数据库中，触发后自动删除；服务器每5秒检测一次
- Render免费测试部署使用临时SQLite文件；实例休眠、重启或重新部署后规则可能丢失，不作为可靠告警服务
- 触发后循环播放提示音和震动，最长5分钟；全屏提醒提供“关闭提醒”按钮，关闭后立即停止
- 已授权系统通知时，后台通过Web Push发送锁屏通知；浏览器不支持震动时仍保留页面声音与系统通知
- iPhone须将HTTPS站点添加到主屏幕，从主屏幕打开后启用通知
- iOS不允许网页在锁屏后持续震动5分钟；点开锁屏通知进入页面后，可持续声音/震动直至手工关闭或满5分钟
